# 삼성 TV에 "집안일" 앱 아이콘 설치 (개발자 모드, 심사 없음)

이 폴더(`tv-app`)는 TV 홈 화면에 아이콘을 만드는 **껍데기 앱**입니다.
열면 `https://home.kastlemath.com/tv.html`로 이동합니다. (로그인·사진은 웹 쪽 그대로)

> 필요한 것: Windows PC, 삼성 계정, TV와 PC가 **같은 와이파이/공유기**

## 1. PC에 Tizen Studio 설치 (처음 한 번)
1. https://developer.samsung.com/smarttv/develop/getting-started/setting-up-sdk/installing-tv-sdk.html 에서 Tizen Studio 설치
2. 설치 후 **Package Manager** 실행 → `Extension SDK` 탭에서 아래 둘 설치
   - **TV Extensions-x.x**
   - **Samsung Certificate Extension**

## 2. TV를 개발자 모드로
1. TV 리모컨으로 **앱(Apps)** 화면으로 이동
2. 리모컨 숫자판(또는 화면 숫자 키패드)으로 **1 2 3 4 5** 입력
3. 창이 뜨면 **개발자 모드: 켜짐(On)**, **호스트 PC IP**에 이 PC의 IP 입력 → 확인
   - PC IP 확인: 명령 프롬프트에서 `ipconfig` → IPv4 주소
4. **TV를 껐다 켜기** (전원 코드 말고 리모컨 전원)

## 3. TV 연결
1. Tizen Studio → **Tools → Device Manager**
2. **Remote Device Manager** → `+` → TV IP(TV 설정 → 네트워크에서 확인) 입력 → 추가
3. 추가한 TV 옆 스위치를 **ON** 으로 (연결됨)

## 4. 인증서 만들기 (처음 한 번)
1. **Tools → Certificate Manager** → `+`
2. **Samsung** 선택 → **TV** → 새 인증서 → 삼성 계정 로그인
3. 연결된 TV(DUID)를 선택해서 인증서 생성

## 5. 앱 설치
1. **File → Import → Tizen → Tizen Project** → 이 `tv-app` 폴더 선택
2. 프로젝트에서 우클릭 → **Run As → Tizen Web Application**
3. TV에 "집안일" 앱이 설치되어 실행됩니다. (TV 앱 목록 끝에 아이콘 생성 — 방향키로 앞쪽으로 옮길 수 있어요)

## 주의
- 개발용 인증서라 **만료되면** 앱이 안 열릴 수 있어요 → 그때 4~5번만 다시
- 일부 TV는 완전히 껐다 켜면 개발자 모드가 풀려요 (앱 아이콘은 보통 남아 있음)
- 앱 안에서 처음 한 번 비밀번호(2864)를 입력해야 해요
- 주소가 바뀌면 `index.html`의 `URL` 값만 고치고 다시 5번
